# AI-Flash-Card-Generator

An AI-powered Flash Card Generator built using Python, Streamlit, and Google Gemini API.

## Features

- Enter a topic or study notes in the text area.
- Generate 5 AI-powered flash cards automatically.
- Each flash card contains a question and answer.
- Simple and user-friendly Streamlit interface.
- Uses Google Gemini to generate flash cards.

## Technologies Used

- Python
- Streamlit
- Google Gemini API
- python-dotenv

## How to Run

1. Clone the repository.
2. Create and activate a virtual environment.
3. Install the required dependencies.
4. Create a `.env` file and add your Google API key:

GOOGLE_API_KEY=your_api_key_here

5. Run the application:

streamlit run app.py
